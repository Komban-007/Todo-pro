# Product Context

**Last updated:** 2026-07-24
**Updated by:** Pat (Phase 1b Elicitation)

## Decision Philosophy
- Prioritize user experience and UI simplicity over adding secondary features.
- If a feature adds clutter or visual complexity, defer or reject it.
- Core workflows (reminders, task reordering, due dates) must function flawlessly.

## Quality Bar
- Fast, smooth UI responsiveness with zero perceived lag.
- Clean, Apple Notes / Google Tasks inspired aesthetic with high contrast and smooth micro-interactions.
- Reliable browser notification reminders without missed triggers.

## Scope Style
- Strict "start small and iterate" MVP scope.
- Keep features minimal for V1 to ensure core usability is top-tier before adding secondary capabilities.

## User Model
- Personal productivity users seeking a clean, distraction-free daily task manager.
- Frustrated by overly complex, bloated task management apps with cluttered interfaces.

## Non-Negotiables
- App must not feel slow or laggy under any condition.
- UI must remain clean and un-cluttered at all times.
- Reminders and task reordering must be rock solid and bug-free.
